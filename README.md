# E-commerce Analytics: Продажи vs Аренда

Анализ годовых данных e-commerce платформы (август 2023 — июль 2024) с разделением на два бизнес-сегмента и прогнозом на квартал вперёд.

---

## О проекте

Датасет содержит ~116 000 заказов за год. Ключевая особенность — признак `is_rental` разделяет данные на два **принципиально разных бизнес-сегмента**:

| Сегмент | Описание | Семантика статуса `Returned` |
|---|---|---|
| **Продажа** (`is_rental = 0`) | Классическая продажа товаров | Возврат → **потеря денег** |
| **Аренда** (`is_rental = 1`) | Сдача предметов в аренду | Завершение аренды → **успех** |

Игнорирование этого различия приводит к ложным выводам, поэтому весь анализ ведётся **раздельно по сегментам**.

---

## Ключевые выводы

1. **Аренда маржинальнее, но рискованнее.** Хотя продажи дают 65% выручки, аренда приносит ~49% чистой прибыли. При этом ~26% строк аренды убыточны (против ~4.5% в продажах).

2. **Обнаружен артефакт среза данных (right-censoring).** Провал аренды в июне-июле 2024 (суммарная прибыль −41 000 ₽) — **не реальное ухудшение бизнеса**, а следствие того, что 90% июльских аренд находятся в статусе `Shipped` (незавершены). После фильтрации по `Returned`:
   - доля убыточных падает с 71.5% до 39.3%
   - медианная прибыль с −8.69 ₽ до +2.82 ₽

3. **Концентрация прибыли умеренная (близко к правилу Парето).** 50% прибыли формируют 14–20% заказов, 80% — 42–49%. Горстки «крупных сделок», определяющих результат, нет.

4. **Гипотеза о концентрации убытков в дешёвом сегменте подтверждается частично.** Доля убыточных в Q1 = 30.7%, в Q5 = 23.0% — эффект монотонный, но малый по величине. В июле все квинтили сходятся к ~70%, что указывает на другой механизм провала.

5. **Крупнейшие убытки — артефакт незавершённых аренд.** Топ-10 убытков июля — все `Shipped`. Крупнейшие убытки формируются частичными начислениями по активным арендам, а не бизнес-событиями.

## Структура анализа

### 1. Загрузка и проверка качества данных

- Очистка внешних кавычек в CSV
- Проверки: `shape`, `NaN`, диапазоны, множества статусов
- **Ключевое наблюдение:** `product_id` — не идентификатор товара (число уникальных = числу строк)

### 2. Сегментация и производные метрики

- `revenue = price × count`
- `profit = profit_per_item × count`
- Разделение на `df_sale` и `df_rent`

### 3. Общая картина бизнеса

- Вклад сегментов в выручку / прибыль / объём
- Средний чек и средняя прибыль на заказ

### 4. Числовой анализ по сегментам

- Распределения: `price`, `profit_per_item`, `revenue`, `profit`
- Анализ убыточных строк
- Гистограммы и boxplot-сравнение
- Выбросы и асимметрия

### 5. Временной анализ

- Динамика прибыли (MA7)
- Помесячная агрегация
- Паттерн по дням недели
- Поиск точки перелома в аренде
- **Артефакт среза данных в июле 2024**

### 6. Проверка гипотез

- **H1:** концентрация убытков по ценовым квинтилям
- **H2:** разбивка убытков по статусам
- **H3:** выбросы vs системная проблема

### 7. Корреляции и структура заказов

- Корреляционные матрицы по сегментам
- Позиций на заказ, средний / медианный чек
- Pareto-анализ прибыли

### 8. Подготовка временных рядов

- Недельные ряды прибыли / выручки / заказов
